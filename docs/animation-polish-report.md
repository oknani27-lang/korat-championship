# DMR — ตรวจและเก็บคุณภาพการนำเสนอ 0–60 วินาที

19 ตุลาคม 2026

## สิ่งที่ปรับ

- ลดขอบว่าง SVG และยกเลิกการบีบภาพให้สูงเพียง 90 px บน desktop ใช้ความกว้างการ์ดเดิมเต็มพื้นที่ ขยายตัวอักษร SVG จาก 11 เป็น 13 หน่วยภาพ ส่วนล็อตตัวอย่างคงขนาดรองที่อ่านได้
- ช่วง R201/T301 ตัดขอบว่างด้านบนเพิ่ม โดยยังเก็บกรอบถัง สัญลักษณ์และวาล์วครบ ช่วงอื่นคงขอบเขตเฉพาะสิ่งที่ต้องแสดง ตรวจตัวอักษรภายใต้ transform ไม่หลุด viewBox
- ขยับสัดส่วนการ์ดด้านขวาจาก 0.95:1.05 เป็น 0.7:1.3 บน desktop โดยไม่เพิ่มความสูง workspace การ์ดสูตรยังเลื่อนอ่านได้ และภาพหลักในอีกการ์ดเห็นได้มากขึ้น คง toolbar ใต้โมเดลและ sheet/navigation ด้านล่าง มือถือยังเรียงการ์ดแนวตั้ง
- เพิ่ม `ProcessRouteSummary` เพื่อแสดงป้ายตัวอย่าง/รอยืนยันเหนือภาพ และสาย/ปลายทางสั้น ๆ ใต้ภาพ ไม่ซ้ำแผงรายละเอียด ไม่สร้าง popup
- คง registry สี/รูปทรงเดิมทั้งหมด แยกน้ำ สารละลาย เซลล์ ตะกอน ไอน้ำ ผลิตภัณฑ์และซอง พร้อมคำอธิบายเชิงสัญลักษณ์ รายละเอียดเดิมไม่ได้ลบ
- ชุดอนุภาค instancing ที่ไม่มีอนุภาคมองเห็นใช้ `visible=false` เพื่อไม่ส่ง draw call ทรัพยากรและ instance matrices ยังคงใช้ซ้ำ ไม่มี Canvas, timer, animation loop หรือ geometry ใหม่
- แก้ข้อความ fallback เก่าที่ระบุว่าภาพยังจบที่ 51 วินาทีให้เป็นข้อความทั่วไปสำหรับข้อมูลที่ยังไม่พร้อม ไม่เปลี่ยนขอบเขตกระบวนการจริง

ไม่เพิ่มสูตรเคมี ประสิทธิภาพ ผลตรวจ อัตราการไหล หรือเส้นทางกระบวนการ ไม่เปลี่ยนจำนวน/ตำแหน่งเชิงเวลาในฟังก์ชันจำลอง DR701 ยังเป็นตัวอย่างทางเลือก H701/FD701 ไม่เปิดร่วมกัน และซองสุดท้ายยังกักรอตรวจ

## ค่าที่วัดก่อน/หลัง

วัดด้วย Chrome headless + SwiftShader ที่ URL local เดียวกัน ขนาด desktop 1366×768 และ mobile emulation 390×844 หยุดที่เวลาเดียวกัน ตรวจหลัง warm-up ของชุด geometry ที่มีอยู่ เนื่องจาก GPU upload ของวัตถุที่ซ่อนเป็นแบบ lazy การเพิ่มครั้งแรกจึงไม่ถูกนับเป็น resource leak

## ตรวจรอยต่อและการใช้งาน

ชุดตรวจใหม่ครอบคลุมก่อน/ตรง/หลังรอยต่อ 3, 6, 11, 17, 23, 26, 30, 38, 44, 48, 51, 56 และ 60 วินาที ไม่ทดสอบภาพหลัง 60 ที่อยู่นอกขอบเขต ภาพรวมก่อน 3 วินาทีเป็นข้อความภาพรวมตามเดิม ไม่ใช่ SVG กระบวนการที่ขาด

ตรวจ pause และ reverse scrub ในทุกกลุ่มกระบวนการ ไม่เพิ่ม crossfade หรือภาพเชื่อมท่อเพื่อปิดช่องว่าง การเปลี่ยน schematic คือการเปลี่ยนมุมมองเล่าเรื่อง ไม่ใช่สมดุลมวล/อัตราปฏิกิริยา จำนวนสัญลักษณ์ต่างช่วงไม่ได้ใช้รายงานประสิทธิภาพ

คงภาพซองที่ 60 วินาทีและสถานะกักรอตรวจ กด Play หลังจบเริ่มรอบใหม่ที่ 0 ปุ่ม Next/Previous/เลือกขั้น/Restart และ hidden-tab ใช้ระบบเวลาเดิม

## ข้อจำกัดที่คงไว้

ไม่มีการเปิด R102 น้ำคืน R401/T302 น้ำล้างเข้าบำบัดร่วม หรือท่อผลิตภัณฑ์แห้งที่ยังไม่ยืนยัน ไม่เลือกเทคโนโลยี W601 ไม่สื่อว่า filtrate เป็นน้ำบริสุทธิ์ หรือผลิตภัณฑ์เป็นโปรตีนบริสุทธิ์/ผ่านการรับรอง

Desktop จำกัดความสูงรวมเพื่อให้ปุ่มขั้นตอนอยู่ในจอ รายละเอียดการ์ดจึงต้องเลื่อนภายใน ส่วน mobile ต้องเลื่อนหน้า ไม่มีการรับรองอุปกรณ์ทุกขนาดหรือ FPS บนอุปกรณ์จริง

คำเตือนเดิม: viewer bundle มากกว่า 500 kB และ `THREE.Clock` deprecated ไม่มีการแก้ dependency หรือแยก bundle ที่ไม่เกี่ยวกับงานรอบนี้

ไม่แก้/สร้าง Blender หรือเปลี่ยน GLB ไม่ commit, push หรือ deploy รักษางานเดิมที่ยังไม่ได้ commit
