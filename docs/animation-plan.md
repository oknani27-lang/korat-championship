## 3. Workflow ที่ใช้เป็นฐาน

สายหลัก: T101 → EC101 → F101 → R201 → T301 → T302 → R401 → F501

- T101 รับและพักปัสสาวะ ควบคุมการส่งวัตถุดิบ
- EC101 ปรับสภาพด้วยไฟฟ้าเคมี ได้สารละลายพร้อมตะกอน และมีสายก๊าซ/สารละลายข้างเคียงที่ต้องแยกจัดการ
- F101 แยกของเหลวไป R201 และตะกอน/side stream ที่กำหนดไปแขนง R102
- R102 กู้คืนฟอสฟอรัส เป็นแขนงพัฒนา ได้ของแข็งและ mother liquor ที่กัก/ตรวจ ทางกลับยังไม่กำหนด
- R201 ทำไนตริฟิเคชันแบบ MBBR มี G201 จ่ายอากาศ/ก๊าซสำหรับจุลินทรีย์
- T301 กักสารละลายรอตรวจ ผ่านเกณฑ์จึงส่งต่อ ไม่ผ่านไปกักหรือจัดการแยก
- T302 ผสม stock ที่อนุมัติ น้ำที่ผ่านเกณฑ์ และสารอาหารเสริม ตรวจสูตรก่อนส่งเข้าเพาะ
- R401 เพาะ Limnospira indica มีแสง อาหาร แหล่งคาร์บอน/ก๊าซ พร้อม G401, P401 และ AIT401 ตามหน้าที่ในข้อมูลเครื่อง
- F501 แยกชีวมวลเข้มข้นออกจากน้ำเลี้ยง เทคโนโลยีกรองยังต้องเลือก

สายชีวมวล: F501 → T501 → วิธีแปรรูปที่เลือก → PK801 → T801

- T501 ล้างและลดน้ำชีวมวล น้ำล้างไปกัก ไม่คืนถังเพาะโดยตรง
- H701 ให้ความร้อน, DR701 อบแห้ง, FD701 ทำแห้งแบบแช่เยือกแข็ง เป็นทางเลือกหรือใช้ร่วมเมื่อมีหลักฐาน ไม่บังคับต่ออนุกรมทั้งสาม
- FD701 ต้องมีการเตรียมแช่แข็งก่อน ไม่แสดงว่าเทชีวมวลเปียกเข้าแล้วได้ผลิตภัณฑ์แห้งทันที
- PK801 บรรจุ ซีล และระบุล็อต ส่วน T801 กักรอตรวจ การซีลไม่ใช่การอนุมัติบริโภค

สายน้ำ: filtrate ที่กำหนด → W601 → T601 → ตรวจผ่าน → จุดใช้ที่อนุมัติ

- W601 ยังไม่เลือกเทคโนโลยี ห้ามแสดงกลไกภายในที่สื่อว่าเลือกเทคโนโลยีแล้ว
- T601 เป็นจุดกักและอนุมัติตามการใช้งาน น้ำไม่ผ่านต้องไป hold/rework/disposal
- ผู้ใช้ต้องการวงจรกลับ R401 แต่ไฟล์ข้อมูลเครื่องยังไม่ยืนยันปลายทางนี้ จึงเก็บเป็น proposed route ที่รอยืนยัน
- หากต้องเล่าเจตนานี้ในฉบับร่าง ให้ใช้เส้นประพร้อมป้าย “ข้อเสนอ: คืนหลังผ่านเกณฑ์” โดยยังไม่ปล่อยอนุภาคไหลผ่าน

## 8. งานเชื่อมเข้ากับเว็บ

สิ่งที่ใช้ต่อได้: React + TypeScript + R3F/Drei, ตัวโหลด GLB, การเลือกชิ้นส่วน, เครื่องมือกล้อง, ProcessSheet, parser และชนิดข้อมูล ProcessStep/MachinePart/FlowPath

| ส่วนงาน | จุดเชื่อมในโครงการ | สิ่งที่ต้องเพิ่ม |
| --- | --- | --- |
| GLB | `public/models/dmr-machine.glb`, `src/data/config.ts` | export หลังทบทวน workflow; เปลี่ยน modelUrl จาก null |
| รายการเครื่อง | `src/data/machine-parts.json` | ID คงที่ จับคู่ชื่อ export จริง และสมาชิก assembly |
| เส้นทาง | `src/data/flow-paths.json` | พิกัดตรงท่อและพอร์ต แยก visual path จากสถานะยืนยัน |
| ขั้นตอน | `src/data/process-steps.json` | เติมขั้นตาม storyboard พร้อม active parts/camera/outputs |
| สีและชนิดสาร | เสนอ `src/data/substances.ts` | สี รูปทรง ชื่อ สถานะ และระดับโมเลกุล/ไอออน/เซลล์ |
| เวลาเดียว | `src/simulation/simulator.ts`, `useSimulator.ts` | เพิ่ม global playhead, play-all และเวลาต่อขั้น; ไม่สร้าง timer แยกแต่ละเอฟเฟกต์ |
| เชื่อมภาพ | `src/App.tsx`, `MachineViewer.tsx` | ส่ง playhead/phase ให้ฉากจริง; ตอนนี้ timelineProgress ยังไม่ส่งเข้าตัว viewer |
| อนุภาค | เสนอ `FlowParticles.tsx` | ใช้ instancing และคำนวณตำแหน่งจาก playhead/seed คงที่ ไม่สุ่มใหม่ทุก render |
| ภาพในถัง | เสนอ `ProcessEffects.tsx` | ระดับน้ำ ตะกอน การผสม เซลล์ และการแยก โดยไม่แอบอ้างสมดุลมวลเชิงตัวเลข |
| กล้อง | เสนอ `ProcessCamera.tsx` | fit bounds จริง/เลือกฉาก/คืนมุมมอง และให้ผู้ใช้ยกเลิกกล้องอัตโนมัติได้ |
| อธิบายสาร | ProcessSheet และ legend ใหม่ | ชื่อ สี รูปทรง active species และคำอธิบายสั้น ไม่ใส่ค่าตรวจแต่งขึ้น |

ชิ้นส่วนโมเดล GLB เป็น static rigid machine เป็นหลัก การไหลทำบนเว็บ ไม่สร้าง keyframe ให้ทุกโมเลกุลใน Blender หากมี animation clip ที่จำเป็นต้อง export ต้องเชื่อมเวลาร่วมและตรวจการลากย้อนด้วย

พิกัด GLB ต้องตรวจการแปลงแกน Blender Z-up ไปเว็บ Y-up รวมถึง scale/translation; ใช้ transform เดียวกับ flow paths และ camera focus ไม่คัดลอกพิกัดดิบโดยไม่ตรวจ

Canvas ปัจจุบันใช้ frameloop demand ต้อง invalidate ขณะเล่นหรือมีกล้องเคลื่อนไหว และกลับไปหยุด render เมื่อ idle ไม่เปลี่ยนเป็น render ต่อเนื่องตลอดเวลาโดยไม่มีเหตุผล

## 9. ลำดับลงมือและเกณฑ์ตรวจรับ

### ช่วง 1 — ล็อกสเปกการเล่าเรื่อง

- ผลงาน: เอกสารนี้ รายการข้อขัดแย้ง storyboard สี และ mapping เบื้องต้น
- ตรวจรับ: ไม่มีทางกลับ R102 ที่สมมติ ไม่มีน้ำไม่ผ่านเกณฑ์กลับถัง ไม่มี H701/DR701/FD701 ทำงานพร้อมกันแบบบังคับ
- ก่อนเผยแพร่ต้องเลือกวิธีแปรรูปและยืนยันทางคืนน้ำ หากยังไม่ได้คำตอบ ให้ฉบับสาธิตหยุดที่ขอบเขตที่ข้อมูลรองรับ

### ช่วง 2 — ใส่เครื่องจริงแบบ static

- สำรวจ object/triangle/material/draw calls และจัดกลุ่มด้วย registry/export structure โดยไม่เปลี่ยนต้นฉบับ .blend
- ส่งออก GLB แยกสำหรับเว็บเป็น asset ใหม่ ไม่สร้าง .blend ใหม่ และไม่บันทึกการเตรียม export ทับไฟล์หลัก
- ตรวจวัสดุ ชิ้นส่วน curve ที่ต้องแปลงเป็น mesh ตัวอักษร/ป้าย และไม่รวมวัตถุซ่อนเก่าที่ถูกแทนแล้ว
- ปรับ fit-to-model และเริ่มด้วยภาพรวมเครื่องครบ ไม่ตัดปลายเครื่อง
- ตรวจรับ: โหลด GLB สำเร็จ mapping เครื่องหลักครบ หมุน/ซูม/เลือกได้ ไม่มี error ในเส้นทางปกติ และส่วน fallback ยังใช้ได้

### ช่วง 3 — ทำต้นแบบอนุภาคหนึ่งช่วง

- เริ่ม T101 → EC101 → F101 โดยยังไม่เปิดแขนง R102 ที่รูปท่อขัดข้อมูล
- แสดงอนุภาคแยกชนิด เส้นทางถูกต้อง และคำอธิบายการแยกของแข็ง
- เชื่อม playhead กลางพร้อม pause/scrub/restart และเลือกขั้น
- ตรวจรับ: เวลาเดียวกันให้ภาพเดียวกันทั้งเล่นไปข้างหน้าและลากย้อน ไม่มีอนุภาคกระโดดหรือเดินต่อขณะ pause

### ช่วง 4 — ขยายครบหนึ่งกระบวนการ

- เพิ่ม R201 → T301 → T302 → R401 → F501 และแขนงน้ำ/ชีวมวลตามข้อมูลที่ยืนยัน
- เพิ่มการเล่นต่อเนื่อง ย้ายขั้นอัตโนมัติเมื่อจบ โดยไม่รีเซ็ต scene หรือสร้าง Canvas ใหม่
- เพิ่มสถานะ hold/pass/reject แบบตัวอย่างและแยกก๊าซกับของเหลว
- เพิ่มล้าง แปรรูปที่เลือก บรรจุ ซีล ล็อต และกัก
- ตรวจรับ: เล่นครั้งเดียวจบที่ T801, scrub ข้ามขั้นได้, เลือกขั้นแล้วข้อความ กล้อง และอนุภาคสอดคล้องกัน

### ช่วง 5 — เพิ่มความชัดเจนในการนำเสนอ

- เพิ่ม molecular close-up, cutaway ที่เลือกเฉพาะเครื่อง, legend และคำอธิบายสั้น
- แสดงอิเล็กโทรด biofilm เซลล์ และการกรองด้วยสัญลักษณ์ที่แยกกัน
- ไม่ใช้ full X-Ray ทั้งเครื่องตลอดเวลา เพราะอ่านยากและเพิ่มงานโปร่งใส
- ตรวจรับ: ผู้ชมแยกชนิดสารและอธิบายทางเข้า–ออกของขั้นหลักได้ ไม่ต้องพึ่งสีอย่างเดียว

### ช่วง 6 — ตรวจรับก่อนขึ้นเว็บ

- ทดสอบ desktop/mobile, การสัมผัส, pause/resume, restart, reverse scrub, เปลี่ยนขั้นเร็ว และซ่อนแท็บ
- ทดสอบโมเดลโหลดช้า/หาย WebGL ล้มเหลว และการคืนสภาพ
- profile บนเครื่องเป้าหมายจริง ปรับจำนวนอนุภาค DPR และ transparency ไม่รับประกัน FPS ก่อนวัด
- รัน typecheck, unit tests, lint สำหรับโค้ดเว็บ, build และ browser regression พร้อมชุดทดสอบอนิเมชันที่เพิ่มใหม่
- ตรวจ scientific wording และรอยืนยันก่อนใช้เป็นสื่อภายนอก การ deploy เป็นงานแยกจากการสร้าง

## 10. รายการข้อเท็จจริงและข้อจำกัดที่ต้องแสดงให้ตรง

- ลูกบอล/เส้นเกลียวเป็นภาพแทนที่ขยายขนาด ไม่ใช่สัดส่วนโมเลกุลต่อเครื่องจริง
- การเปลี่ยนสีสารแสดงประเภท ไม่ใช่การเปลี่ยนสีสารละลายจริง
- น้ำหลังแยกเซลล์ยังอาจมีสารละลายอยู่ ไม่เท่ากับน้ำบริสุทธิ์
- ไนตริฟิเคชัน การกรอง การอบ และการซีลไม่ใช่หลักฐานว่าผลิตภัณฑ์ปลอดภัยสำหรับบริโภค
- ไม่สมมติว่า R102 ให้ struvite ทุกกรณี หรือให้สารที่พร้อมเติมถังเพาะทันที
- ไม่แสดง CO₂ ไหลในสายของเหลวโดยไม่มี gas–liquid interface ที่กำหนด
- ไม่สร้างปริมาณสารสัมพันธ์ สมการเคมี อัตราการไหล เวลาพัก ค่าเซนเซอร์ หรือผลตรวจโดยไม่มีแหล่งข้อมูล
- งานแปรรูปที่ใช้ถาด/ภาชนะต้องเล่าเป็น batch transfer; ท่อสีทองที่เพิ่มก่อนหน้าไม่ใช่ข้อสรุปว่าของแห้งปั๊มผ่านได้จริง
