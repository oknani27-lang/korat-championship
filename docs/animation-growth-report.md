# DMR — อนิเมชันช่วง 17–38 วินาที

วันที่ตรวจ: 19 ตุลาคม 2026

> รายงานนี้บันทึกงานช่วง 17–38 วินาที ต่อมาเพิ่มเก็บเกี่ยว กู้คืนน้ำ และล้างช่วง 38–51 วินาทีแล้ว ดู `animation-harvest-report.md` สำหรับสถานะปัจจุบัน ข้อความในรายงานนี้ที่ระบุ 38–60 รอพัฒนาเป็นสถานะก่อนการขยายรอบล่าสุด ตำแหน่งการ์ดและปุ่ม Play/Pause ใช้ layout ล่าสุดตาม `viewer-layout-report.md`

## ผลงาน

เว็บแสดงภาพการไหลบนท่อและ schematic ถึงช่วงเพาะ R401 โดยคงลำดับนำเสนอ 60 วินาที เวลาเดียว `playheadSeconds` ควบคุมอนุภาค สมการ ข้อความ อุปกรณ์ที่เน้น และสถานะตัวอย่าง ไม่มี timer เพิ่มตามเอฟเฟกต์ ไม่มี Canvas ใหม่

| เวลาเล่าเรื่อง | ภาพที่เพิ่ม |
| --- | --- |
| 17–23 s | F101 ส่งของเหลวเข้า R201; schematic แสดง biofilm ตัวกลางและลำดับ NH₄⁺ → NO₂⁻ → NO₃⁻ แยกยูเรียและน้ำไว้ ไม่แสดง ureolysis ที่ยังไม่ได้อธิบาย |
| 23–26 s | T301 กักล็อตและแสดงตัวอย่างการอนุมัติที่ 25.25 s ก่อนส่งต่อ ไม่แสดงค่าผลตรวจหรือตีความว่าทุกล็อตผ่าน |
| 26–30 s | T302 ผสม น้ำและสารเสริมที่สมมติว่าผ่านเกณฑ์แสดงใน schematic เท่านั้น ตัวอย่างอนุมัติสูตรที่ 29 s ก่อนส่งตามท่อไป P301 |
| 30–38 s | อาหารจาก P301 เข้า R401; น้ำ ไนเตรตและเซลล์เกลียวเชิงสัญลักษณ์เดินตามวงจร P401/AIT401 ภายใน schematic แสดงแสง ก๊าซ และเซลล์ที่เพิ่มแบบย่อเวลา |
| 38–60 s | ยังคงคำอธิบายและสูตรตามขั้น พร้อมป้ายรอพัฒนาภาพการไหล ไม่มีอนุภาคบนท่อช่วงนี้ |

รูปแบบกระชับ รายละเอียดเต็ม สูตรและแหล่งอ้างอิงอยู่ในแผงด้านล่าง ไม่มีป๊อปอัปหรือปุ่มย่อ/ขยาย Start Demo เริ่มทันทีจนจบ กด Next/Previous/เลือกขั้นแล้วเล่นต่อ Restart กลับ 0 แล้วเล่น ลาก timeline เพื่อพักตรวจและใช้ Start Demo เล่นต่อ ซ่อนแท็บแล้วไม่นับเวลาที่ซ่อน

## Schematic และส่วนที่รอยืนยัน

| ส่วน | วิธีแสดงและข้อจำกัด |
| --- | --- |
| G201 | ไม่แสดงอนุภาคบนท่อก๊าซ ปลาย `WF2_G201_R201` ห่าง bounding box ปั๊ม 0.14 หน่วยโมเดล และ `REF_AIR_TO_G201` ห่าง filter 0.17 หน่วยโมเดล ใช้ฟองโปร่งใน schematic เพื่อสื่อหน้าที่ก๊าซ ไม่ระบุว่าเลือก aeration technology แล้ว |
| G401 | สายคาร์บอน/side loop/exhaust มีรูปทรง แต่ gas–liquid interface และเทคโนโลยียังไม่ยืนยัน ใช้ schematic ไม่มี CO₂ เคลื่อนในสายของเหลว |
| น้ำและสารเสริม T302 | มี water header ในโมเดล แต่การอนุมัติแหล่งน้ำและพอร์ตสารเสริมไม่ครบ แสดง additions เฉพาะ schematic ไม่ปล่อยอนุภาคบนท่อน้ำจริง ไม่สมมติสูตรผสม |
| AIT401 | เส้นไป–กลับแตะ wetted-interface anchor เดียวกัน ใช้เป็น overlay ตาม loop intent แต่ไม่อ้างว่ามี engineered inlet/outlet แยกที่ผ่านการออกแบบแล้ว ไม่มีค่า sensor สมมติ |
| R102 / น้ำคืน R401 | ไม่เปิดอนิเมชันแขนงเหล่านี้ ข้อขัดแย้งเดิมและการอนุมัติจุดใช้น้ำยังอยู่ |
| ภายในถัง | Biofilm การเปลี่ยนรูปไนโตรเจน ผสม กักอนุมัติ แสง/เซลล์/ก๊าซเป็น schematic ที่มีป้ายชัด ไม่เปิดผิวโมเดลหรือทำ Smart X-Ray |

ตัวเลขช่องว่างเป็นระยะในโมเดลประกอบภาพ ไม่ใช่มิติรับรองสำหรับผลิตเครื่อง สมการใช้ข้อมูลเคมีและแหล่งอ้างอิงเดิมในแผงล่าง ไม่มีการสร้างค่าจลนพลศาสตร์ อัตราการไหล สูตรอาหาร ผลตรวจ หรือผลผลิตใหม่ จำนวน/สี/ขนาดสัญลักษณ์ไม่ใช่สมดุลมวล และไม่ใช่สีของสารจริง

## การทำงานและทรัพยากร

- เพิ่ม `growthFrame(seconds)` แบบ pure function; ตำแหน่ง ชนิดสาร สถานะอนุมัติและจำนวนเซลล์ที่เห็นคำนวณจากเวลา ไม่สะสมตำแหน่งหรือสุ่มใหม่
- อนุภาคบนท่อเป็น finite packet ตามระยะสะสมของ centerline ไม่มีการข้ามช่องว่างหรือเลือกแขนงที่ไม่ยืนยัน
- Registry กลางเพิ่ม NH₄⁺ เครื่องหมายบวก, NO₂⁻ สี่เหลี่ยม, NO₃⁻ หกเหลี่ยม, ก๊าซวงกลมโปร่ง, สารเสริมรูปดาว และเซลล์เกลียว พร้อมชื่อใน legend
- 296 instance slots รวม 6 ชุด geometry/material บนท่อ ไม่ใช่ 296 อนุภาคที่มองเห็นพร้อมกันทุกเวลา; ก๊าซและสารเสริมอยู่ใน SVG schematic เท่านั้น
- ใช้ geometry/material ซ้ำ ขณะลากเวลาหรือเปลี่ยนขั้นไม่มีการเพิ่มชุดใหม่ Tube geometry ของเซลล์เกลียวใช้ร่วมกันผ่าน instancing
- คงการหมุน ซูม เลือกอุปกรณ์ Reset และ fallback เดิม ไม่เพิ่มกล้องอัตโนมัติ

## ผลตรวจ

- `npm test`, `npm run typecheck`: ผ่าน รวมรอยต่อ 17/23/26/30/38 s, เวลากัก/ปล่อย, การคงน้ำและยูเรีย, pure/deterministic frames และเปรียบเทียบทุก centerline กับ audit
- ESLint และ Oxlint สำหรับโค้ดเว็บและตัวสร้างข้อมูล: ผ่าน
- `npm run build`: ผ่าน มีคำเตือนขนาด bundle ของ viewer มากกว่า 500 kB
- Browser regression: 16 ชุดผ่าน รวม clock เดียว hidden-tab cleanup touch fallback และ Canvas identity
- Animation regression: desktop 1440 และ mobile 390 px ผ่าน ตรวจทุกจุดของ 11 เส้นอยู่ในขอบเขต mesh ท่อใน GLB และลากไป–กลับได้ matrices/SVG เดิม ตรวจ material isolation, resource stability, idle rendering, Next เล่นต่อ และเล่นถึง 60 s แล้วหยุด
- Inline chemistry/layout: 12 ขั้นที่ 1440/768/390/320 px ผ่าน สูตรและข้อความไม่ล้นแนวนอน ไม่มี popup หรือปุ่มย่อ/เล่น/หยุด
- Real model integration: 1440/768/390 px และ missing-model fallback ผ่าน ชิ้นส่วนต้นฉบับ 646 ชิ้นและ mapping 24 เครื่องยังครบ
- มี warning เดิมจาก dependency `THREE.Clock` deprecated ไม่มี console error ในเส้นทางปกติ

ตรวจภาพจริงของไนตริฟิเคชันและเพาะบน desktop/mobile รวมภาพรอยต่อที่บันทึกแล้ว ภาพอยู่ใน `test-results/animation-prototype/stage-{เวลา}-{ความกว้าง}.png`, `details-{เวลา}-{ความกว้าง}.png` และภาพล่าสุดของรายละเอียดใน `test-results/process-chemistry/{ชื่อขั้น}-{ความกว้าง}.png` รายงาน JSON อยู่ในโฟลเดอร์เดียวกัน ทั้งหมด Git ignore ไว้ การตรวจ mobile เป็น viewport emulation ไม่ใช่ benchmark บนโทรศัพท์จริง
